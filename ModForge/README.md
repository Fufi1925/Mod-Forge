# ModForge – Discord Security & AutoMod Bot

Vollständiger, skalierbarer Discord Security & AutoMod Bot mit Web‑Dashboard.
Powered by BotForge 🔒

## Einrichtung

1. Repository klonen
2. virtuelle Umgebung anlegen und `pip install -r requirements.txt`
3. `.env`-Datei mit deinen Zugangsdaten füllen
4. MongoDB starten
5. `python run.py` ausführen
