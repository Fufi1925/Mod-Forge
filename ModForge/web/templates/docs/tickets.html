🎫 Tickets

Ticket-System

Vollständiges Support-Ticket-System mit Kategorien und Transkripten.

📋 Einrichtung

Nutze /ticket setup um das Ticket-System zu konfigurieren. Wähle einen Kanal für das Ticket-Panel und definiere Kategorien.

🏷️ Kategorien

Erstelle verschiedene Ticket-Kategorien wie Support, Bug-Report, Bewerbung etc. Jede Kategorie kann eigene Berechtigungen und Formulare haben.

📝 Transkripte

Beim Schließen eines Tickets wird automatisch ein HTML-Transkript erstellt und in einem Log-Channel gespeichert.

⚙️ Commands

/ticket open– Neues Ticket erstellen
/ticket close– Ticket schließen
/ticket add– User zum Ticket hinzufügen
/ticket remove– User entfernen
