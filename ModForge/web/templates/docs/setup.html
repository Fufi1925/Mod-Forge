Setup Guide

In 3 einfachen Schritten zu einem sicheren Server.

1

Bot einladen

Klicke auf „Bot einladen" auf der Startseite und wähle deinen Server aus. Der Bot benötigt Administrator-Berechtigung für volle Funktionalität.

2

Dashboard öffnen

Melde dich mit Discord an unter /login. Wähle deinen Server und konfiguriere die Module im Dashboard.

3

Module aktivieren

Aktiviere Anti-Nuke, Anti-Raid, AutoMod und weitere Module. Nutze /setup im Discord für Schnelleinrichtung.
