Moderation Commands

Alle Tools für die manuelle und automatische Moderation.

/warn Verwarnt einen User mit Grund und Case-ID
/mute Stummschaltung mit optionaler Dauer
/kick Kickt einen User vom Server
/ban Bannt einen User permanent oder temporär
/case Zeigt Details eines Moderation-Cases
/purge Löscht mehrere Nachrichten auf einmal
/lockdown Sperrt einen Channel oder den gesamten Server
