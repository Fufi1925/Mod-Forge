📡 API

API Documentation

Integriere ModForge in deine eigenen Anwendungen mit unserer REST API.

GET /healthz

Gibt den aktuellen Health-Status des Bots zurück.

Response: {"ok": true, "bot_ready": true, "latency": 42}
GET /metrics

Prometheus-kompatible Metriken im Text-Format.

modforge_guilds 142
modforge_members 48291
modforge_latency_ms 38
GET /live/api/activity

Gibt die letzten 50 Bot-Aktivitäten als JSON-Array zurück.

Response: [{"kind": "spam", "text": "...", "ts": "..."}]

🔐 Authentifizierung

Die API nutzt Discord OAuth2 für Benutzer-Authentifizierung.
Dashboard-Sessions werden über ein HTTP-Only Cookie (modforge_session) verwaltet.
Admin-Endpoints benötigen eine separate Admin-Session.
