{# ═══ RULES ═══ #}
📝 Auto-Nickname aktivieren
Bot setzt automatisch Prefix/Suffix basierend auf den Rollen des Users
z.B. " | " oder " • ". Bei Replace ohne Wirkung.
Höchste Rolle in der Liste gewinnt
🔄 Auf bestehende Mitglieder anwenden
Beim Aktivieren werden alle aktuellen Member umbenannt
{# ═══ SERVER-TAG ═══ #}
🏷️
Server-Tag — Wenn User einen bestimmten Tag in ihrem Namen führen (z.B. [XYZ]), erhalten sie automatisch eine Rolle. Perfekt für Clan-Tags.
🏷️ Server-Tag-System aktivieren
Bot scannt Nicknames nach dem Tag und vergibt Rolle
🔁 Bei Tag-Entfernen Rolle wegnehmen
User verliert die Rolle wieder sobald er den Tag entfernt
{# ═══ SANITIZE ═══ #}
🧹
Bereinigt unleserliche oder beleidigende Nicknames automatisch
🆎 Unicode-Spam entfernen
Zalgo, Zero-Width Joiner, RTL-Override → wird gelöscht
🔣 Nur ASCII erlauben
Nicht-lateinische Zeichen werden durch Standard-Nickname ersetzt
🤖 Hoist-Schutz
Nicks die mit Sonderzeichen beginnen (um oben zu erscheinen) bekommen Standard-Nick
